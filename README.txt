# AS Tour & Travels Website

Files:
- index.html
- style.css
- script.js

Upload all three files to your GitHub Pages repository.

The website includes:
Home, Services, Tour Packages, Train Booking, Why Choose Us, About, Contact, Privacy Policy, Terms & Conditions, and Refund/Cancellation Policy.

The `script.js` is configured with the Google Apps Script Web App URL supplied for this project.

Before publishing, replace placeholder contact details/address/email and add your real Google Maps embed if needed.

Important: The site does not promise 100% ticket confirmation. Booking depends on availability and provider rules.
